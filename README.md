# aiswfootballpredict

머신러닝과 통계 기법을 이용하여 국가대표 축구 경기의 승패를 예측해주는 웹페이지이다. 웹페이지에서 예측하고 싶은 국가대표 대회를 선택하고 홈팀 과 어웨이팀을 입력하면 경기에 대해 예측한 확률과 승패를 알려준다. 

경기 예측은 푸아송 분포와 3개의 머신러닝 기법을 통해 진행된다.
웹페이지 내에서의 예측은 푸아송 분포라는 통계 기법을 통해 진행되며, 머신러닝을 통한 예측은 구동 시간이 너무 오래 걸려 웹페이지 내에서는 예측을 진행하지 못하지만 랜덤포레스트, XGboost 알고리즘, 로지스틱 회귀 모델을 이용하여 3개의 모델을 개발하였다.

웹페이지를 통해선 푸아송 분포를 통한 예측 결과를 직접 확인하고, 웹페이지 외부의 모델을 이용해 추가적인 예측을 진행해 예측 결과를 비교해본다면 정확한 예측이 가능할 것이다.

예상 효과: 축구는 전 세계에서 가장 인기가 많은 스포츠이며, 한국에서도 국가대표 스포츠 중에서 가장 많은 인기를 끌고 있는 종목이다. 그로 인해 사람들이 축구 경기에 대해 예측하는 것은 흥미를 끄는 일이 될 수 밖에 없는데, 이러한 축구 경기 예측을 실제 데이터를 기반으로 머신러닝과 통계 기법을 활용해 수행한다면 전문가 못지않게 높은 정확도로 예측이 가능할 수 있다. 따라서 우리 팀은 이 웹페이지가 축구에 관심이 있는 사람들이 이용하면 충분히 즐거움을 느낄 수 있는 서비스라고 생각하였다. 

특히 현재 많은 축구 정보 제공 웹사이트가 존재하지만 경기에 대한 정보를 제공하는데에 그치거나 예측을 제공하더라도 당장 앞선 경기에 대한 예측만 제공되며, 경기 예측을 통한 재미를 목적으로한 빅데이터 기반 축구 경기 예측 사이트는 많지 않다. 따라서 우리 팀의 웹페이지는 빅데이터를 기반으로 축구 경기 예측만을 목적으로 하는 서비스를 만들어, 실제 진행되는 경기가 아니더라도 축구 팬들이 원하는 대진의 경기를 직접 예측해볼 수 있게 하면서 축구 팬들이 더욱 즐겁게 축구를 즐길 수 있게 하고, 높은 성능의 모델을 개발해 이를 통해 축구 산업이 더욱 활성화되는데 기여하고자 한다.
